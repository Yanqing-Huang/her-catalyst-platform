# HER-Catalyst 仿真模拟平台

泡沫镍负载过渡金属磷化物体系多维筛选及析氢催化性能研究 —— 配套数字化平台。

北京化工大学大学生创新创业训练计划项目成果。

## 在线访问

- GitHub Pages：`https://yanqing-huang.github.io/her-catalyst-platform/`（推送后自动开启）

## 功能模块

| 模块 | 说明 |
|---|---|
| 📊 总览看板 | 样品统计、η@10 排名、活性-动力学联合分布 |
| 🧪 实验样品库 | 23 组实测数据（Ni-Co-P / Ni-Fe-P × 4/6/8h × 多配比）统一管理 |
| 🔧 数据修正 | 原始 LSV 数据四步修正流水线：异常点剔除 / 平滑降噪 / 基线校正 / iR 补偿 |
| 🔬 多维筛选 | 体系 × 配比 × 水热时间筛选 + 性能热力图 |
| 📈 LSV 曲线分析 | 多样品极化曲线叠加对比 |
| 🧬 仿真模拟 | 实测数据标定的响应面模型，预测 η@10 / η@100 / Tafel，输出响应面热力图 |
| 📚 文献数据库 | 调研文献性能数据结构化入库，文献 vs 实验对标 |
| 📑 系统化分析 | Tafel 机理判定、文献规律交叉验证、文献分位对标、自动生成分析结论 |

## 使用方法

纯前端静态页面，零依赖安装：

1. 直接用浏览器打开 `index.html`（需与 `echarts.min.js` 在同一目录）
2. 数据保存在浏览器 localStorage，支持 JSON / CSV 导入导出

## 数据来源

- 实验数据：本课题三电极体系（1 M KOH）实测 η@10、η@100、Tafel 斜率
- 文献数据：课题组调研的已发表文献（详见平台内文献数据库模块）

## 说明

仿真模拟模块为经验响应面模型，仅用于工艺趋势预估，不能替代实验验证。
